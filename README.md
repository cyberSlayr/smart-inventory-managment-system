# Smart Inventory Management System

A beginner-friendly **Smart Inventory Management System** built using **C++**. This project allows users to manage products, track inventory, search for products, update product details, and monitor stock levels.

The project will be developed step by step, starting with basic C++ concepts and later adding **Data Structures and Algorithms (DSA)** and **MySQL database integration**.

## Features

### Basic Features

* Add Product
* Display All Products
* Search Product by ID
* Update Product Details
* Delete Product
* Sell Product
* Low Stock Alert

### DSA Features

* Fast product searching using `unordered_map`
* Undo last operation using `stack`
* Customer order management using `queue`
* Product sorting by name, price, or quantity

### DBMS Features

The advanced version will store data using MySQL.

Planned tables:

* Products
* Sales
* Suppliers

The project will use database concepts such as:

* CRUD Operations
* Primary Keys
* Foreign Keys
* SQL Queries
* Joins
* Aggregate Functions

## Project Development

### Phase 1: Basic C++

Build the basic inventory system using:

* `vector`
* Classes
* Functions
* Loops and conditions

### Phase 2: DSA Integration

Improve the project by adding:

* `unordered_map`
* `stack`
* `queue`
* Sorting algorithms

### Phase 3: MySQL Integration

Connect the C++ application with a MySQL database to store products, sales, and supplier information permanently.

## How to Run

Compile the program:

```bash

```

Run the program:

